# Helios Application Screenshots

This directory stores visual verification screenshots of the core interfaces across all roles in the Helios platform.

## Captured Screenshots

1. **`login_page.png`**: Multi-role login portal (`/login`) featuring email, password, visibility toggle (eye icon), and role selection hints.
2. **`admin_home.png`**: System Administrator Home console (`/admin/home`) showing platform metrics, top organizations by revenue, and 14-day pipeline run activity.
3. **`team_home.png`**: Operations Team Member Home console (`/team/home`) displaying assigned organization status and quick access actions.
4. **`client_home.png`**: Organization Owner Home portal (`/client/home`) showing business welcome, recent activity, and quick navigation.
5. **`pending_uploads.png`**: Pending Ingestion Approvals (`/admin/uploads` or `/team/uploads`) where uploaded CSV/Excel files await schema confirmation and review.
6. **`pipeline_health.png`**: Pipeline Health & Telemetry console (`/admin/pipeline-health`) showing stage-by-stage status, execution duration, and failure recovery controls.
7. **`owner_dashboard.png`**: Store Performance & Analytics dashboard (`/client/dashboard`) displaying revenue, orders, profit metrics, and interactive charts.
